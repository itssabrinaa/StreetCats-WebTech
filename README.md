# StreetCats-WebTech

<img src="https://github.com/itssabrinaa/StreetCats-WebTech/blob/main/streetcats-backend/public/img/sc-logo.png" width="200" height="200" />

"StreetCats", progetto per l'esame di Tecnologie Web, docente Starace, Università degli Studi di Napoli Federico II.

**Istruzioni per l'esecuzione:**

1. Back-end
2. 
Posizionarsi nella cartella "StreetCats-WebTech".

Posizionarsi nella cartella "streetsats-backend".


Rinominare il file ".env.dummy" in ".env", e completarlo con le informazioni necessarie.


Eseguire " ` npm install ` ".

Eseguire " ` npm start ` ".


2. Front-end

Posizionarsi nella cartella "StreetCats-WebTech".

Posizionarsi nella cartella "streetsats-frontend".


Eseguire " ` npm install ` ".

Eseguire " ` ng serve ` ".


3. Test E2E

Posizionarsi nella cartella "StreetCats-WebTech".

Posizionarsi nella cartella "streetsats-frontend".


Eseguire " ` npx playwright install ` ".
Eseguire " ` npm run test:e2e ` ".
